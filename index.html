🏰 Window Dungeon

🖥️

데스크톱 Chrome 전용 세미나 데모

Window Dungeon은 실제 모니터 공간에 여러 개의 브라우저 창을 띄우는 데스크톱 최신 웹 API(Window Management, Document PiP) 기반 기술 데모입니다.
스마트폰 환경에서는 다중 팝업 스냅이 지원되지 않으므로, 노트북이나 PC의 Chrome 브라우저에서 접속해 주세요!

✅ 링크가 복사되었습니다! 노트북으로 공유해 보세요.
⚠️ 비호환 브라우저 감지 현재 브라우저에서는 Window Management API 및 Document PiP 미니맵이 지원되지 않습니다. 완벽한 다중 창 스냅과 플로팅 레이더를 위해 데스크톱 Chrome(또는 Edge) 접속을 권장합니다.

새 던전 세션 시작

각 브라우저 창이 던전의 방이 됩니다.
열쇠🔑를 찾아 탈출문🚪을 열고 다음 스테이지로 나아가세요!

💡 권한 및 조작 안내
• 팝업 차단 해제 및 창 관리 권한이 필요합니다.
• 방향키(또는 WASD)로 이동하며, 문에 닿으면 다음 방 창이 자동으로 열립니다.
• 게임 중 언제든 [M] 키를 누르면 미니맵이 플로팅으로 열립니다.
Master Server Running (30Hz)
⚠️ 이 창을 닫으면 게임 세션이 종료됩니다.
